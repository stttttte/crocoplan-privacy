Requirements

iPhone and iPad require iOS / iPadOS 18 or later. Mac requires macOS 15 or later. Cross-device sync requires the same Apple Account, available iCloud storage and a network connection.

Projects, acceptance and AI updates

Use the + action to create a project. Add text, links or files as task deliverables, then explicitly accept tasks. For AI Batch Update, copy the project prompt into your chosen AI, import its structured JSON and preview the changes. The app does not call an AI API or read other accounts automatically.

If sync is delayed

Check the Apple Account, iCloud, connection and storage on both devices, reopen the app and allow time for system sync. Do not uninstall the app, erase data or replace the cloud container as a troubleshooting shortcut. Export a separate copy first from the workspace actions menu.

Copies and Mac data folders

Use Export a Copy in the workspace actions menu to save a JSON copy. Archiving preserves a project. Uninstalling does not erase cloud content or an external Mac data folder. Keep an external disk available if you select a data folder on it.

Contact support

Include your app version, device, OS version, steps and error message. Redact private content from screenshots. Do not send Apple Account passwords, verification codes or AI service keys.
